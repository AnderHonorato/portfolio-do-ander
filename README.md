# Portfólio — Ander Flow

Portfólio de projetos de Anderson Honorato, com HTML, CSS e JavaScript e opções de tema claro e escuro.

## Projeto em destaque

### MenteVerso × Flow Programação Guiada

Plataforma educacional com psicanálise e programação, incluindo mascote interativo, 10 trilhas de programação, 30 aulas publicadas, questões e laboratório de código.

- [Experimentar MenteVerso](https://menteverso-wmt0j1.v2.appdeploy.ai/)
- [Repositório do MenteVerso](https://github.com/AnderHonorato/mente-verso)

O curso de programação e a psicanálise compartilham o mesmo ambiente web, mas autenticação unificada, ranking em servidor e certificados ainda são funcionalidades em desenvolvimento.

## Como visualizar

Abra `index.html` em um navegador ou publique este repositório como site estático. O ícone do MenteVerso fica em `img/icons/menteverso.svg`.
